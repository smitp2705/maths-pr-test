# Student Scores — Mini Research Report

A Python data analysis project on a student scores dataset (~5000 records).

## Files

- `students_scores_report.ipynb` — Main Jupyter notebook
- `students_scores.csv` — Dataset
- `requirements.txt` — Dependencies

## Dataset Columns

`Student_ID`, `Age`, `Math_Score`, `Science_Score`, `English_Score`, `Hours_Studied`, `Pass_Fail`

## What's Inside the Notebook

**Part A — Theory:** 8 short answers covering Mean/Median/Mode, Variance, Normal Distribution, Skewness, Probability, Bayes' Theorem, and Eigenvalues.

**Part B — Practical:**
- Mean, Median, Mode of Math Score
- Range, Variance, Std Dev of Science Score
- Pass probability & contingency table
- Histogram, Normal curve, Q-Q plot
- Dot product, vector norms, angle between vectors

## Setup

```bash
pip install -r requirements.txt
jupyter notebook students_scores_report.ipynb
```
